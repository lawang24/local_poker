# PokerNow reference recordings

These user-supplied recordings are the primary visual and interaction reference.
Watch the appropriate recording before changing the UI; use the existing live
private table only for states or interactions not captured here.

| Local file | Layout | Original download |
| --- | --- | --- |
| `phone.mov` | Phone | `phone pokernow.mov` |
| `desktop.mov` | Desktop/computer | `computer_pokernow.mov` |

The recordings were moved from Downloads on November 18, 2026. Videos and any
extracted frames in this directory are ignored by Git; this inventory is tracked.
They are local assets and will not appear automatically in fresh clones or linked
worktrees. Use the files in the original checkout or copy them locally as needed.

Cite the filename and timestamps when documenting a comparison. Match orientation
and game state; do not treat video pixel dimensions as known CSS viewport sizes.
Report missing files and uncovered states explicitly. Live fallback checks must
follow the shared-table instructions in [AGENTS.md](../../AGENTS.md).
